# 2026-11-17 Android 实测

环境：macOS arm64 主机，Android Emulator API 35 arm64 / Pixel 7，1080×2400、density 420，对应 412 CSS 像素。使用联网版 1.2.6 的 debug APK 登录真实账号；release APK 使用相同前端资源，另行校验稳定签名和打包内容。未使用手机实体设备。

黄金副本首次搜索期间，2 GB 模拟器的 WebView 出现长时间 CPU 和内存压力，尚未开始副本。按用户要求停止应用并重启模拟器，以 4 GB 内存重新打开同一 APK；分辨率和密度不变。重启前独立读取服务端，确认仓库 10/10、森林 10/10、黄金 0/10 且无活动副本。慢搜索中断单独保存为 `apk-dungeon-golden_slime-slow-preflight.json`，不计为完成轮数。

## 装备与饰品强化

六组战斗完成后，读取 204 条背包记录、55 件饰品，按魔女 M 路线和最低掉血目标核对推荐，再通过 APK 应用一项装备变更、执行一项强化。此操作发生在六组计时之后，不改变上表条件。

- 装备方案只替换宝石项链。`POST /api/inventory/equip` 返回 200，回读确认目标项链已装备、旧项链已卸下，同部位只有一件装备；再次计算无待应用动作。面板 ATK 25655 → 26105，DEF 18262 → 18710，SPD 6805 → 6354，HP 718 不变。推荐是当前面板下的部位评分，不代表对每只怪物的战斗最优证明。
- 强化保留新装备项链，消耗一件未装备、未锁定的同类备用项链。仅一次 `POST /api/accessory/enhance` 返回 200：+0 → +1，稀有词条，防御百分比增加 4（随机副词条 3% → 7%，另有物品固定 DEF+10%）。回读确认保留物仍装备、材料记录已移除、碎片 7293 → 7292、守护符未消耗、全部锁定物品原样保留；最终 DEF 19307。
- 未进行购买、抽取、重置或批量强化。证据见 `apk-equipment-enhancement.json`。
