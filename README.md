# 史莱姆竞速实验室（联网版）

仅供本机使用的联网开发版本，基于同一套 JavaScript 模拟核心生成 macOS、Windows 和 Android App。四只史莱姆以绿、蓝、红、黄四个无碰撞点呈现。

本版本保留离线版全部功能，并用于只读同步用户自己的实盘数据。它不自动下注，不保存其他玩家 ID，也不得配置 Git 远程或发布到 GitHub。凭据仅放在权限为 `600` 的 `.env.slime-race.local`，该文件不会进入应用安装包。详细规则见 [VARIANT.md](VARIANT.md)。

## 已实现规则

- 两圈比赛，中心线单圈默认按完赛时间反推为 2000 距离单位。
- 起跑速度为基础速度的 0.8～1.2 倍。
- 首次事件约等待 5 秒，之后事件结束即进行下一次判断。
- 每次事件：15% 绊倒、15% 疾冲、70% 正常，持续 1～1.5 秒。
- 每 50 ms 更新一次，当前速度每帧向目标速度趋近 10%。
- 宽赛道和内外圈路径成本；默认全宽约等于 1 秒移动距离。
- 每半圈进入弯道时可能选择新的横向目标，四个点之间没有碰撞。
- 相同随机种子在三个平台产生相同赛果。
- 可视化单场比赛、实盘历史胜率、赛前双选建议和最多 50000 场蒙特卡洛模拟。
- 可快速追加或批量导入 459 场基线之后的新实盘冠军；新增记录只保存在本机，模拟盘不会计入实盘。
- 可导入当前四只史莱姆的实盘押注池，按公众追热门强度估算封盘池，并同时展示池占比和无手续费毛返还倍数。
- 可设置可用筹码、本场投入上限和最小筹码单位，枚举不下注、单押和所有双押分配，推荐最大期望净收益方案。
- 推荐计算会考虑自己的下注同时增加总奖池和对应史莱姆押注，从而压低自身封盘赔率；没有正期望方案时建议不下注。
- 可在 App 内使用用户自己的账号登录固定实盘站点；密码不保存，会话只用于当前本机同步。
- 当前比赛、累计胜场和四只史莱姆聚合盘口每 3 秒刷新，最近场次与个人统计每 30 秒刷新。
- 逐笔盘口会立即按史莱姆聚合，其他玩家 ID 不进入界面、本地存储或日志；联网功能不会执行下注、领奖或管理操作。

路径选择属于估算项，因为当前没有原游戏的转向算法。界面中可以调整赛道宽度、弯道换道概率和横穿赛道时间，并用实测胜率与完赛时间校准。

## 本地开发

```bash
npm install
npm start
```

运行检查：

```bash
npm run check
```

## 打包与产物

macOS：

```bash
npm run dist:mac
```

产物位于 `release/`：

- `史莱姆竞速实验室（联网版）-1.1.0-arm64.dmg`
- `史莱姆竞速实验室（联网版）-1.1.0-arm64-mac.zip`

当前本地包没有 Apple Developer ID 签名。在其他 Mac 首次打开时可能需要右键应用并选择“打开”。

Windows（推荐在 Windows 环境执行）：

```bash
npm run dist:win
```

生成 x64 NSIS 安装器与免安装便携版：

- `史莱姆竞速实验室（联网版） Setup 1.1.0.exe`
- `史莱姆竞速实验室（联网版） 1.1.0.exe`

Android 需要 JDK 21 和 Android SDK 35：

```bash
npm run android:sync
npm run android:open
```

也可以直接构建调试 APK：

```bash
npm run android:apk
```

Android 调试 APK 默认位于 `android/app/build/outputs/apk/debug/app-debug.apk`。当前已验收的易识别副本位于：

- `release/史莱姆竞速实验室（联网版）-1.1.0-android-debug.apk`

该 APK 使用 Android 调试证书签名，可以直接侧载安装，但不能直接提交应用商店；正式上架需要创建私有发布密钥并生成签名的 release AAB/APK。
联网版 Android 清单只为实盘只读同步申请网络权限。联网功能仍在本机开发，完成安全验收前不生成或发布联网版安装包。

在受限网络环境下，如果 Electron 运行时已经提前解压，可以分别使用 `npm run dist:mac:offline` 和 `npm run dist:win:offline`。
