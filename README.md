# 史莱姆竞速实验室（联网版）

仅供本机使用的联网开发版本，基于同一套 JavaScript 模拟核心生成 macOS、Windows 和 Android App。四只史莱姆以绿、蓝、红、黄四个无碰撞点呈现。

本版本保留离线版全部功能，可同步用户自己的实盘数据，并在用户逐笔核对、二次确认后远程下注或领取奖励。日常助手会低频读取进度和题目，为站点所有者提供单次自动复述、自动完成 100 次点击、自动提交 60.00 秒报时，以及独立的 ±0.20 秒随机误差测试；躲避游戏保持官方页面原有流程。联网版不保存其他玩家 ID，只同步到指定的 GitHub private 仓库，不进入公共离线仓库。凭据仅放在权限为 `600` 的 `.env.slime-race.local`，该文件不会进入应用安装包或 Git 提交。详细规则见 [VARIANT.md](VARIANT.md)。

## 已实现规则

- 两圈比赛，中心线单圈默认按完赛时间反推为 2000 距离单位。
- 起跑速度为基础速度的 0.8～1.2 倍。
- 首次事件约等待 5 秒，之后事件结束即进行下一次判断。
- 每次事件：15% 绊倒、15% 疾冲、70% 正常，持续 1～1.5 秒。
- 每 50 ms 更新一次，当前速度每帧向目标速度趋近 10%。
- 宽赛道和内外圈路径成本；默认全宽约等于 1 秒移动距离。
- 每半圈进入弯道时可能选择新的横向目标，四个点之间没有碰撞。
- 相同随机种子在三个平台产生相同赛果。
- 可视化单场比赛、实盘历史胜率、赛前双选建议和最多 50000 场蒙特卡洛模拟。
- 可快速追加或批量导入 459 场基线之后的新实盘冠军；新增记录只保存在本机，模拟盘不会计入实盘。
- 可导入当前四只史莱姆的实盘押注池，并按“追历史热门、追高赔率冷门、混合群体、均匀分散”四种公众行为预测封盘池。
- 可选择“最大期望、单场胜率优先、均衡风险、本金保护、高赔率价值”五种个人策略；所有策略仍要求正增量期望，不会只因胜率或倍数高而盲目下注。
- 本金保护策略按用户设置的最大本金亏损比例限制累计投入。由于整场最多双押，它不能对四种冠军结果同时保证零亏损；若要求所有赛果绝对保本，唯一方案是不下注。
- 支持手动填写本场已提交下注；联网完整同步时会自动识别当前盘口的个人仓位。旧下注视为不可撤回，只比较追加前后 `EV(现有 + 追加) - EV(现有)`。
- 推荐计算会考虑自己的追加同时增加总奖池和对应史莱姆押注，从而压低自身封盘赔率；累计最多选择两只，没有正增量期望时建议等待或停止追加。
- 可在 App 内使用用户自己的账号登录固定实盘站点；本地 Electron 开发版启动时会优先从权限为 `600` 的 `.env.slime-race.local` 自动登录，账号密码只由主进程读取。
- 当前比赛、账户碎片、待领取奖励、累计胜场和四只史莱姆聚合盘口默认每 4 秒自动刷新，最近场次与个人统计每 40 秒刷新；自动实时更新可随时关闭。
- 复述输入、手动点击、下注编辑、下注核对和所有远程提交期间会暂停自动刷新，避免碎片、奖励或盘口更新干扰当前操作；手动全量同步仍可使用。
- 远程下注最小 1 碎片；提交前重新校验余额、封盘状态和最多双押，之后必须二次确认。超时只同步核对，不自动重试。
- “按最优建议一键下注”优先复用最近 5 秒内的建议；建议过期时只并发刷新当前场次、聚合盘口和余额。每笔提交前后仍用同一轻量快照重新校验，双押继续串行且任一失败立即停止。
- 实时快照只重算当前主推荐；三种封盘情景稳健性留给全量同步或手动“重新计算”，避免轮询时反复阻塞界面。
- 待领取奖励按笔展示，每笔都需用户确认后调用固定赌马奖励接口，不提供自动领取。
- 日常助手低频读取复述、点击、躲避和报时四类任务进度；可手动提交复述，也可将当前服务器题目自动复述一次。
- 点击任务保留手动点击，也可显式自动完成一轮 100 次；每次操作只提交一轮，不会在后台无限循环。
- 报时任务可自动提交一次 60.00 秒结果；也可显式执行一次随机误差测试，从 59.80～60.20 秒的百分之一秒档位中随机取值，并显示提交值、绝对误差和服务端判定。躲避游戏及其成绩提交保持原官方页面流程，不在 App 内自动化。
- 躲避和报时待领奖励仍会在领取前重新核对进度，并要求用户确认；POST 失败或超时不会自动重试。
- 本地逐场监控只记录聚合池、自己的仓位、余额和比赛状态，拟合公众追热门/追高赔率倾向，并分析个人组合在三种封盘情景下的稳健性。
- 逐笔盘口会立即按史莱姆聚合，其他玩家 ID 不进入界面、本地存储或日志；联网功能不会执行开赛、奖金注入、重置或管理操作。

路径选择属于估算项，因为当前没有原游戏的转向算法。界面中可以调整赛道宽度、弯道换道概率和横穿赛道时间，并用实测胜率与完赛时间校准。

## 打开联网版

首次运行需要在终端安装依赖：

```bash
cd /Users/marisa/slime-race-simulator
npm install
```

以后每次打开只需：

```bash
cd /Users/marisa/slime-race-simulator
npm start
```

应用窗口打开后，本地 Electron 开发版会自动使用 `.env.slime-race.local` 中的固定测试账号登录。凭据不会进入渲染层、输入框或日志；环境文件缺失或自动登录失败时会回退到手动登录。点击“退出当前账号”会停止轮询、清除本地会话并恢复手动登录，本次窗口会话内不会再次自动登录；重新启动应用后仍会按环境文件自动登录。远程下注与领取继续要求用户确认。

联网版源码和安装产物只发布到指定的 GitHub private 仓库。公共 GitHub 仓库仍只包含严格隔离的离线版。

## 本地检查

运行检查：

```bash
npm run check
```

使用环境文件中的本地测试账号执行一次真实随机报时测试：

```bash
npm run test:timer-error
```

该命令会真实提交一次报时，并可能增加测试账号的报时进度或待领奖励；不会输出账号、密码或 Cookie，也不会自动重试 POST。

## 打包与产物

macOS：

```bash
npm run dist:mac
```

产物位于 `release/`：

- `史莱姆竞速实验室（联网版）-1.1.2-arm64.dmg`
- `史莱姆竞速实验室（联网版）-1.1.2-arm64-mac.zip`

当前本地包没有 Apple Developer ID 签名。在其他 Mac 首次打开时可能需要右键应用并选择“打开”。

Windows（推荐在 Windows 环境执行）：

```bash
npm run dist:win
```

生成 x64 NSIS 安装器与免安装便携版：

- `史莱姆竞速实验室（联网版） Setup 1.1.2.exe`
- `史莱姆竞速实验室（联网版） 1.1.2.exe`

Android 需要 JDK 21 和 Android SDK 35：

```bash
npm run android:sync
npm run android:open
```

也可以直接构建调试 APK：

```bash
npm run android:apk
```

Android 调试 APK 默认位于 `android/app/build/outputs/apk/debug/app-debug.apk`。当前已验收的易识别副本位于：

- `release/slime-race-lab-online-1.1.2-android-debug.apk`

该 APK 使用 Android 调试证书签名，可以直接侧载安装，但不能直接提交应用商店；正式上架需要创建私有发布密钥并生成签名的 release AAB/APK。
联网版 Android 清单只申请网络权限。调试 APK 只发布到指定的 private 仓库 Release，不发布到公共离线仓库或应用商店。

在受限网络环境下，如果 Electron 运行时已经提前解压，可以分别使用 `npm run dist:mac:offline` 和 `npm run dist:win:offline`。
